# Ech0 Mobile v0.6.0 更新草稿

> 状态：本地草稿，未发布。  
> 构建版本：`versionName = 0.6.0`，`versionCode = 12`。  
> 对外标题：`v0.6.0`。

## 概览

v0.6.0 是一次以「设置中心 2.0」和「网络体验」为主的版本。

设置页从原来的单页长列表，重构为「分类首页 + 二级设置页 + 独立搜索页」；同时补齐账号、实例、网络、存储、阅读、外观、编辑、评论和诊断能力。网络层继续完成并行化、实例隔离、缓存加固和可取消请求，首页与月份面板也改为动态刷新。

## 亮点

- **设置中心 2.0**：分类首页 + 二级设置页，右上角搜索按钮进入独立搜索页。
- **账号与实例入口移到「我的」**：顶部用户卡同时展示账号和当前实例，点击直接进入账号与实例管理。
- **网络与流量可控**：慢速实例兼容、仅 Wi-Fi 图片 / 媒体 / 上传、低流量细分、缓存刷新间隔。
- **网络与请求诊断**：DNS / TCP / TLS / HTTP 四段诊断，最近 20 条请求状态与耗时。
- **存储更清楚**：页面缓存、图片缓存、临时文件、草稿、应用数据分项统计与分开清理。
- **阅读与外观更完整**：字号滑杆、行距、代码字体、图片质量、AMOLED、高对比、减少动画、背景暗化。
- **编辑与评论默认值**：默认图片质量 / 布局 / 私密 / 标签，上传并发、EXIF、重试、发布确认。
- **首页动态刷新**：按缓存间隔静默刷新，回到前台自动检查；月份面板只显示真实有内容的月份。
- **网络请求更快**：友链、发现、详情并行加载；共享连接池；请求可取消；缓存按实例和账号隔离。

## 设置中心 2.0

### 新的设置结构

```text
我的
└─ 顶部账号卡：当前用户 + 当前实例
   └─ 点击进入「账号与实例」

设置首页
├─ 网络与流量
├─ 缓存与存储
├─ 阅读与外观
├─ 编辑与评论
└─ 高级与关于
```

- 设置首页只展示分类卡片，不再把所有设置堆在一个长页面。
- 账号与实例不再占用设置分类，入口合并到「我的」顶部用户卡。
- 每个分类显示图标、标题和动态摘要。
- 点击分类进入独立二级页，顶部标题变为分类名。
- 上一级返回、系统返回键都按「搜索页 → 分类首页 → 关闭设置」逐级返回；从「我的」进入账号与实例时，返回直接回到「我的」。
- 顶部右上角新增搜索按钮，进入独立搜索页后自动聚焦输入框。

### 账号与实例（我的顶部）

- 「我的」顶部账号卡同时展示：头像、昵称、管理员标记、当前实例。
- 点击账号卡直接进入账号与实例页。
- 当前账号卡：头像、昵称、管理员标记。
- 登录有效期：显示 Token 剩余天数或已过期。
- 退出登录、清除 Cookie。
- 已保存实例：保存地址与显示名，不保存 Token。
- 实例切换支持快速切换、删除和当前实例标记。
- 切换实例前明确提示会清除登录状态、Cookie 和页面缓存。
- 测试连接只做只读探测，不再偷偷保存地址或清除登录态。

### 网络与流量

- 慢速实例兼容：本站 API 读超时放宽到 90 秒，上传和图片不受影响。
- 仅 Wi-Fi 加载图片：移动网络下已缓存图片仍可显示。
- 仅 Wi-Fi 播放媒体：音乐和视频内嵌播放受控。
- 仅 Wi-Fi 上传：移动网络下选图后不会自动上传。
- 预加载下一页开关。
- 信息流缓存间隔：3 / 10 / 30 分钟。
- 低流量模式细分：
  - 不加载头像
  - 不加载正文图片
  - 不加载扩展卡封面
  - 不预取扩展卡元信息

### 网络与请求诊断

- 网络诊断：
  - DNS 解析耗时
  - TCP 连接耗时
  - TLS 握手结果
  - HTTP `/api/hello` 状态与耗时
- 请求诊断：
  - 最近 20 条请求
  - 方法、host、路径、状态、耗时、字节数
  - 不记录 Token、Cookie、请求体和响应体

### 缓存与存储

- 页面缓存、图片缓存、临时文件、草稿暂存、应用数据、可用空间分项统计。
- 页面缓存、图片缓存、临时文件、草稿暂存可分别清理。
- 上次刷新时间。
- 图片磁盘缓存上限：150 / 300 / 500 MB。
- 可用空间低于 500 MB 时自动清理图片和页面缓存。

### 阅读与外观

- 字号滑杆：85%–130%。
- 行距：紧凑 / 标准 / 宽松。
- 代码字体：等宽 / 衬线。
- 链接打开方式：应用内浏览器 / 系统浏览器。
- 信息流图片质量：标准 / 高清 / 原图。
- 自动播放 GIF / 视频。
- 相对时间 / 绝对时间。
- 纯黑 AMOLED。
- 高对比度。
- 减少动画。
- 状态栏图标：自动 / 浅色 / 深色。
- 背景暗化 0–60%。
- 主题色预设。

### 编辑与评论

- 默认图片质量：标准 82 / 高清 92 / 原图。
- 默认图片布局：瀑布流 / 网格 / 横向 / 轮播 / 堆叠 / 无。
- 默认私密。
- 默认标签。
- 同时上传数量：1 / 2 / 3。
- 上传前移除 EXIF。
- 上传失败重试：0 / 1 / 2 次。
- 发布前确认。
- 评论身份按实例和账号隔离，不再把 A 站邮箱带到 B 站。
- 评论排序：最早 / 最新。
- 发送评论前确认。
- 评论草稿自动保存，设置页可统一清除。

### 高级与维护

- 自动检查更新开关。
- 检查间隔：24 小时 / 7 天 / 手动。
- 立即检查更新。
- 导出设置 JSON：排除 Token、Cookie、草稿、队列和评论邮箱。
- 导入设置。
- 重置所有设置：保留登录、实例地址、草稿、队列和缓存。
- 清除登录。
- 自定义 User-Agent。
- HTTP 代理 `host:port`。

## 网络与性能

- 统一 `HttpClients` 连接池与分发器，按用途拆分 api / upload / image / remote / thirdParty / update。
- 请求改为可取消的 `Call.await()`，离开页面后不再继续占用连接。
- 分层超时：
  - API read 20 秒
  - 上传 write 180 秒 / call 300 秒
  - 图片 call 45 秒
  - 第三方元数据 call 15 秒
- 401 刷新去重：同一时刻多个 401 只刷新一次。
- 实例与账号隔离：
  - 页面缓存按实例 + 账号分目录
  - 切换 host / 协议清登录态和缓存
  - 草稿和队列携带 `baseUrl`，避免跨实例误发
- 友链并行：
  - 来源并发 `Semaphore(4)`
  - 单来源 8 秒超时
  - 单个来源失败不影响其他来源
- 发现页 5 个接口并行：today / hot / heatmap / tags / onthisday。
- 详情页正文、评论、远端实例信息并行。
- 上传取消：移除图片或重试时取消旧上传协程。
- Coil：内存缓存 25%，磁盘缓存上限可配置。
- `DiskCache`：
  - 单写者 `Mutex`
  - 临时文件 + rename 原子写
  - 详情缓存最多 100 个文件
  - 启动清理旧版 v1 缓存

## 首页与月份面板

- 首页按「信息流缓存间隔」定时静默刷新。
- 从后台回到前台时，缓存过期会静默刷新。
- 静默刷新会更新已加载帖子的内容，并把新帖插入顶部。
- 发布、编辑、删除后仍然立即刷新。
- 首页月份面板不再拼接最近 18 个空月份，只显示实际有内容的月份。
- 友链月份面板同步改为只显示实际有内容的月份。
- 月份面板新增「加载更早」，继续翻页后月份列表动态扩展。
- 月份列表随帖子列表变化自动重组，不需要关闭重开。

## 修复

- 设置页「网络检查」不再保存地址、不再清除登录态。
- 切换实例前增加风险确认。
- 低流量模式文案与实际行为不一致。
- Android 12 以下背景模糊开关仍可点击的问题。
- 首页静默刷新不更新已有帖子内容。
- 首页月份面板出现大量没有内容的月份。
- 友链月份面板仍然出现多余的占位月份。
- 评论身份跨实例复用。
- 评论草稿关闭详情后丢失。
- 上传中移除图片后仍继续上传。
- 切换实例后旧页面缓存可能被读到。
- `Call.await` 恢复后在主线程读取响应体导致 `NetworkOnMainThreadException`。

## 已知限制

- 请求诊断只保留最近 20 条，不做月度流量统计。
- 图片缓存上限和 GIF 解码开关在下次启动应用后生效。
- 评论「热门」排序依赖服务端参数，当前只提供最早 / 最新。
- 代码字体只影响 Markdown 行内代码和代码块。
- 设置搜索按分类关键词定位，不是逐条设置全文搜索。

## 升级方式

- 已安装旧版本：直接覆盖安装 `ech0-mobile-0.6.0.apk`，数据保留（需使用相同 release 签名）。
- 首次安装：允许安装未知来源应用后安装。
- 系统要求：Android 10（API 29）及以上。
- 升级不会清除登录态、草稿、队列或缓存。
- 切换实例只会影响当前实例相关的登录状态和页面缓存。
