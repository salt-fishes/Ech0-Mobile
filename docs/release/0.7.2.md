# Ech0 Mobile v0.7.2

## 概览

v0.7.2 是 0.7.x 的体验升级版：时间线卡片与详情之间加入共享元素转场，发现/我的迁移到统一的 Hero Header + 渐变模糊紧凑栏，搜索、下拉刷新和空态也切到 Material 3 Expressive 组件。同时修复了网络超时/取消时 OkHttp 异步回调导致进程崩溃的问题，建议所有 0.7.x 用户升级。

## 亮点

- 时间线 → 详情共享元素转场：卡片、封面连续过渡，返回恢复原来的列表位置。
- 发现、我的使用与时间线一致的 Hero Header 和滚动后渐变模糊紧凑栏。
- 时间线搜索、设置搜索改用 M3E SearchBar 输入框，保留搜索展开/关闭。
- 下拉刷新、启动页、网络诊断、更新记录和音乐进度统一为 M3E 加载组件。
- 草稿箱、发布队列空态统一为 `EmptyStateCard`。

## 改进

- 共享元素在减少动效、低流量或图片未加载时自动降级为淡入，不阻塞页面打开。
- 详情卡片圆角与时间线卡片统一，避免转场时切角或跳色。
- 编辑器 Snackbar 补上减少动效降级。
- 0.7.0/0.7.1 的主题、设置与图片链路保持不变。

## 修复

- 网络超时或请求取消时，OkHttp 异步回调可能在已完成/取消的协程上再次恢复，导致进程崩溃；现在只在协程仍活跃时恢复，并兜底异常。

## 升级方式

- 已安装 0.7.x：直接覆盖安装 `ech0-mobile-0.7.2.apk`，数据保留（需使用相同 release 签名）。
- 首次安装：允许安装未知来源应用后安装。
- 系统要求：Android 10（API 29）及以上。
