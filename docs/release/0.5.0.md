# Ech0 Mobile v0.5.0

> 状态：开发中，尚未发布。本文作为 v0.5.0 的更新内容清单和验收依据。

## 概览

v0.5.0 重点修好友链的「图片」和「加载更多」两个核心体验，并把卡片能力补齐到接近网页版：GitHub 仓库信息、应用内音乐播放、视频 / 推文 / 位置卡片。阅读侧增加长文本折叠、Markdown 正文图片和二级评论嵌套；编辑侧增加粘贴链接自动识别卡片、去重入口和图片删除清理。

## 亮点

- **友链图片修复**：图片请求改用浏览器 UA，解决第三方图床拦截 OkHttp 默认 UA 导致的 403；正文 Markdown 图片也会渲染，不再只显示附件图。
- **友链分页修复**：远端某页失败不再误判「到底了」，不跳过失败页；底部提供「加载失败，点击重试」，第 2 页、第 3 页可以正常加载。
- **卡片能力补齐**：GitHub 卡片显示仓库头像、描述、Star / Fork；音乐卡片支持应用内播放；视频、推文、位置卡片按网页版交互完善。
- **长文本折叠**：时间线和友链的长正文默认收起，点「展开」查看全文，点「收起」恢复。
- **二级评论嵌套**：按 `parent_id` 把回复显示在一级评论下方，缩进层级参考网页版。
- **发帖卡片自动识别**：点「卡片」后粘贴链接，自动判断 GitHub / B 站 / YouTube / 网易云 / QQ 音乐 / X 推文 / 网站 / 位置，并自动填好字段。
- **图片查看细节**：长按弹窗按钮顺序调整为「取消 / 分享 / 保存到相册」，取消放最左边。

## 改进

- 友链卡片显示服务端 logo、站点名、`@username`、认证标记和标签，信息层级对齐网页版。
- 远端详情继续完善：图片、扩展卡片、评论和身份信息统一使用对方实例的资源地址。
- 编辑器去掉底部重复的「话题」「图片」入口，只保留九宫格选图大框和必要工具。
- 没有图片时隐藏「画质」选项，避免无效设置。
- 删除已上传图片时，对新上传文件调用服务端删除接口；编辑旧帖只解除附件关系，避免误删其他帖子在用的文件。
- 远端请求失败时保留已有内容并给出重试入口，不再静默吞掉错误。
- 低流量模式下继续不请求头像、图片和卡片封面；音乐播放需要用户主动点击。

## 修复

- 友链图片空白：外部图床对 `okhttp/4.12.0` 返回 403，改用浏览器 UA 后可正常加载。
- 友链正文 Markdown 图片不显示：轻量 Markdown 渲染器未处理 `![](...)`。
- 友链下滑没有更多内容：远端分页请求失败被吞掉，`endReached` 被错误置为 true，且页码继续递增导致跳过失败页。
- 友链卡片缺少 `@username`、认证标记和完整标签信息。
- 长文本在时间线和友链中一次性展开，影响浏览。
- 二级评论平铺显示，回复关系不清晰。
- 长按图片弹窗「取消」不在最左侧。

## 升级方式

- 已安装旧版本：直接覆盖安装 `ech0-mobile-0.5.0.apk`，数据保留（需使用相同 release 签名）。
- 首次安装：允许安装未知来源应用后安装。
- 系统要求：Android 10（API 29）及以上。
