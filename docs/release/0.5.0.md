# Ech0 Mobile v0.5.0

> 状态：已构建，等待发布。本文作为 v0.5.0 的更新内容清单和验收依据。

## 概览

v0.5.0 重点修好友链的「图片」和「加载更多」两个核心体验，并把卡片能力补齐到接近网页版：GitHub 仓库信息、应用内音乐播放、视频 / 推文 / 位置卡片。阅读侧增加长文本折叠、Markdown 正文图片和二级评论嵌套；编辑侧增加粘贴链接自动识别卡片、草稿确认和图片删除清理。

## 亮点

- **友链图片修复**：图片请求统一使用浏览器 UA，解决第三方图床拦截 OkHttp 默认 UA 导致的 403；正文 Markdown 图片也会渲染，不再只显示附件图。
- **友链分页修复**：分页改为按来源记录页码，某个实例失败不会拖住其他实例，也不会跳过失败页；底部提供「加载失败，点击重试」，第 2 页、第 3 页可以正常加载。
- **卡片能力补齐**：GitHub 卡片显示仓库头像、描述、Star / Fork；音乐卡片支持应用内播放；视频卡片显示封面并可加载播放器；推文和位置卡片更接近网页版。
- **阅读体验**：时间线和友链的长正文默认收起，点「展开全文」查看；二级评论按 `parent_id` 缩进显示在一级评论下方。
- **编辑体验**：点「卡片」后粘贴链接自动识别 GitHub / B 站 / YouTube / 网易云 / QQ 音乐 / X 推文 / 网站 / 位置；取消发送时可选择是否保存草稿。

## 改进

- 友链卡片显示服务端 logo、站点名、`@username`、认证标记和标签，信息层级对齐网页版。
- 远端详情继续完善：图片、扩展卡片、评论和身份信息统一使用对方实例的资源地址。
- 编辑器去掉底部重复的「话题」「图片」入口，只保留九宫格选图大框和必要工具；没有图片时隐藏「画质」。
- 删除刚上传的图片时调用服务端删除接口；编辑旧帖移除图片只解除附件关系，避免误删其他帖子在用的文件。
- 评论回复改为点评论后自动聚焦并弹出输入法，去掉「回复 xx（取消）」提示行；点界面其他位置自动取消，已写评论草稿时保留回复目标。
- 评论提交增加表单等待余量，并在「提交过快 / 表单失效」时自动刷新令牌重试一次。
- 取消说说编辑时询问保存草稿，可在设置里关闭提示；草稿箱删除增加二次确认。
- 远端请求失败时保留已有内容并给出重试入口，不再静默吞掉错误。
- 低流量模式下继续不请求头像、图片和卡片封面；音乐播放需要用户主动点击。

## 修复

- 友链图片空白：外部图床对 `okhttp/4.12.0` 返回 403，改用浏览器 UA 后可正常加载。
- 友链正文 Markdown 图片不显示：轻量 Markdown 渲染器未处理 `![](...)`。
- 友链下滑没有更多内容：`loadingMore` 状态变化会取消分页协程；远端失败又被误判为到底，且页码继续递增导致跳过失败页。
- 友链卡片缺少 `@username`、认证标记和完整标签信息。
- 长文本在时间线和友链中一次性展开，影响浏览。
- 二级评论平铺显示，回复关系不清晰。
- 长按图片弹窗「取消」不在最左侧。
- 删除已上传图片后服务端残留文件。

## 升级方式

- 已安装旧版本：直接覆盖安装 `ech0-mobile-0.5.0.apk`，数据保留（需使用相同 release 签名）。
- 首次安装：允许安装未知来源应用后安装。
- 系统要求：Android 10（API 29）及以上。
