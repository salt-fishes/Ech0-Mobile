# Ech0 Mobile v0.6.0

## 概览

v0.6.0 以「设置中心 2.0」和「网络体验」为核心。设置页重构为分类首页、二级设置页和独立搜索页；账号与实例入口合并到「我的」顶部用户卡。网络层继续完成并行化、实例隔离、缓存加固与动态刷新，首页和友链的月份面板也改为只展示真实有内容的月份。

## 亮点

- **设置中心 2.0**：分类首页 + 二级设置页，右上角搜索按钮进入独立搜索页。
- **账号与实例入口合并到「我的」**：顶部用户卡展示用户名、管理员标记和当前实例，点击直接管理账号、Token、退出登录和多实例。
- **网络与流量可控**：慢速实例兼容、仅 Wi-Fi 图片 / 媒体 / 上传、低流量细分、预加载开关和信息流缓存间隔。
- **网络诊断**：DNS / TCP / TLS / HTTP 四段检测，展示每一步结果与耗时。
- **请求诊断**：最近 20 条请求的方法、状态、耗时和字节数，不记录 Token 与请求体。
- **存储分项管理**：页面缓存、图片缓存、临时文件、草稿和应用数据分开统计、分开清理；新增上次刷新时间、图片缓存上限和低空间自动清理。
- **阅读与外观更完整**：字号滑杆、行距、代码字体、链接打开方式、图片质量、AMOLED、高对比和减少动画。
- **编辑与评论默认值**：默认图片质量 / 布局 / 私密 / 标签，上传并发、EXIF、重试、发布确认、评论身份隔离和评论草稿。
- **首页与月份动态刷新**：首页按缓存间隔静默刷新；首页和友链月份面板只显示真实有内容的月份。
- **高级维护**：更新间隔、立即检查、设置导出 / 导入、重置设置、自定义 User-Agent 和 HTTP 代理。

## 改进

- 设置页从单页长列表改为「分类首页 → 二级设置页」，系统返回键逐级返回。
- 「我的」顶部账号卡同时展示账号和实例，账号与实例不再占用设置分类。
- 测试连接改为只读探测，不再保存地址或清除登录态。
- 网络基础层统一连接池和客户端矩阵，按 API / 上传 / 图片 / 远端 / 第三方拆分超时。
- 请求支持取消，离开页面后不再继续占用连接；并发 401 只刷新一次 Token。
- 页面缓存按实例和账号隔离，草稿与队列携带 `baseUrl`，避免跨实例误发。
- 友链来源最多 4 路并发、单来源 8 秒超时；发现页 5 个接口并行；详情正文、评论和远端实例信息并行。
- 移除图片或重试时取消旧上传；Coil 内存缓存 25%，图片磁盘缓存可配置。
- 磁盘缓存改为单写者 `Mutex`、原子写和详情缓存 LRU。
- 首页按信息流缓存间隔静默刷新，回到前台时检查缓存；静默刷新会更新已有帖子并插入新帖。
- 首页和友链月份面板新增「加载更早」，随分页动态扩展。
- 低流量模式可分别控制头像、正文图片、扩展卡封面和扩展卡元信息。

## 修复

- 设置页网络检查会保存地址并清除登录态。
- 切换实例没有风险确认。
- 低流量模式文案与实际行为不一致。
- Android 12 以下背景模糊开关仍可点击。
- 首页静默刷新不更新已有帖子内容。
- 首页和友链月份面板出现大量没有内容的月份。
- 评论身份跨实例复用。
- 评论草稿关闭详情后丢失。
- 上传中移除图片后仍继续上传。
- 切换实例后旧页面缓存可能被读到。
- `Call.await` 恢复后在主线程读取响应体导致 `NetworkOnMainThreadException`。

## 升级方式

- 已安装旧版本：直接覆盖安装 `ech0-mobile-0.6.0.apk`，数据保留（需使用相同 release 签名）。
- 首次安装：允许安装未知来源应用后安装。
- 系统要求：Android 10（API 29）及以上。
