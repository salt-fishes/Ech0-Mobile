# Ech0 Mobile v0.5.3

> 状态：已构建，等待发布。

## 概览

v0.5.3 重点修复草稿箱的完整生命周期，并补齐设置、更新记录和内容展示的长期短板。草稿图片改为应用私有暂存，发布、转队列、删除和“不保存”都会清理对应文件；设置页新增网络检查、字体大小和存储空间检查；更新记录改为实时读取 GitHub Release；友链图片与月份侧栏也同步优化。

## 亮点

- **草稿箱全链路修复**：自动保存、恢复、取消、发布、失败转队列和删除统一处理；图片重启后可恢复，发布成功或丢弃后不再留下孤儿文件。
- **关闭时上传也能保存**：存草稿后立即退出，上传完成会自动把 `fileId` 回填到草稿；重新打开不会重复上传。
- **自动保存开关更直观**：原来的「取消发送时询问草稿」改为「自动保存草稿」，开启后关闭编辑器不再弹窗；弹窗内也可勾选「以后自动保存，不再询问」。
- **网络 / 字体 / 存储**：设置页可测实例延迟、调整全局字号、查看缓存与草稿占用并清理。
- **GitHub 更新记录**：关于页的更新记录不再内置，实时读取 GitHub Release，失败时可重试。
- **友链图片自动排版**：改为与首页一致的媒体网格，1 / 2 / 3 / 4+ 张分别使用不同布局。
- **月份侧栏动态刷新**：内容、标签和分页变化后自动更新月份，并高亮当前可见月份。

## 改进

- 草稿图片选图后先复制到 `files/draft_images`，不再依赖 photo picker 的临时权限。
- 草稿保存本地 Uri、已上传 `fileId` 和服务端 URL，三者对齐恢复。
- 发布成功清理草稿记录和本地暂存图，保留已挂到说说上的服务端附件。
- 发布失败转队列时原子移除草稿；已上传图片使用 `uploaded:<fileId>` 复用，不重复上传。
- 队列 Worker 逐张上传并持久化进度，失败重试不会重复上传；超过上限标记失败，避免堵住后续队列。
- 删除服务端文件失败时进入补偿队列，联网后自动重试。
- 卡片类型改为单行横向滑动，不再换行铺开。
- 设置按实例、网络、存储、阅读、外观、流量、编辑、评论身份、高级重新分组。
- 关于页改为 Ech0 Mobile 项目入口，移除 Ech0 上游项目链接。
- 首页移除顶部发布条，仅保留底部中央「+」。

## 修复

- 自动保存开启后关闭编辑器仍然弹出「保存草稿？」。
- 草稿图片重启后失效、恢复时重复上传、删除草稿后服务端文件残留。
- 发布成功 / 转队列后草稿残留，导致内容重复出现。
- 启动时草稿尚未加载完成就清理暂存图，可能误删草稿图片。
- 队列失败条目无限重试、删除后本地 / 服务端文件未清理。
- 发现页热力图刷新后仍为空。
- 友链图片固定三张小图，图片多时显示过小。
- 月份列表重复、选中月份与滚动位置不同步。
- 首页顶部发布入口与底部「+」重复。

## 升级方式

- 已安装旧版本：直接覆盖安装 `ech0-mobile-0.5.3.apk`，数据保留（需使用相同 release 签名）。
- 首次安装：允许安装未知来源应用后安装。
- 系统要求：Android 10（API 29）及以上。
