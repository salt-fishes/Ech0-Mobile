# Ech0 Mobile v0.3.0

## 概览

0.3.0 把「随手打开就看最新」的启动链路补齐：先显示缓存，再静默同步时间线、发现和友链内容，同时加上启动品牌动效。主题色从固定色块改为可自由取色的色盘，并在关于页加入 GitHub Release 版本检查。所有 0.2.0 用户可直接覆盖升级。

## 亮点

- 启动先显示缓存，再静默拉取最新时间线 / 发现 / 友链；切换 Tab 仍按 3 分钟 TTL，不会频繁请求。
- 新增树标启动动效与「正在同步最新内容…」提示，每个进程只播放一次。
- 主题色改为 160dp 色相 / 饱和度色盘，支持拖动即时预览；保留动态取色、4 种背景与深色模式。
- 新增 GitHub Release 版本检查：启动静默检查，关于页「检查更新」可手动触发，发现新版本后可查看更新记录并前往下载。
- 点赞计数统一：列表页、详情页头部与操作行共用同一份计数，点赞状态跨页面同步。

## 改进

- 错误提示统一：页面级错误用错误卡片，瞬时错误走全局 Snackbar；取消类异常不再显示为刷新失败。
- 友链聚合支持 Markdown、媒体缩略图、「N 图」标记和来源 chip，对比度与条数对齐。
- 标签可点：时间线筛选、发现页标签跳转筛选。
- 信息密度调整：发现页去掉重复作者、预览省略、热门去重；两图改两列；关于页技术栈默认收起。
- 底部 dock 增加 scrim，统一底部留白，修复窄屏底部漏出小图标。
- 真机适配：站点 Logo 失败时回退树标；361dp 窄屏设置页背景预览自动换行。

## 修复

- 真机出现「刷新失败：The coroutine scope left the composition」：取消类异常统一忽略。
- 站点 Logo URL 失效时顶栏空白：品牌树标垫底 + 远端 Logo 覆盖。
- 单帖两图时使用三列导致右侧留白：改为两列。
- 设置项「设置 / 友链」显示调试 IP：改为站点名 / 域名摘要。
- 冷启动 DataStore 尚未就绪时误弹「连接实例」引导：改为等首帧数据后再判断。
- 详情、设置等覆盖页里的 Snackbar 被页面盖住：全局提示层移到覆盖页之上。

## 升级方式

- 已安装 0.2.0：直接覆盖安装 `ech0-mobile-0.3.0.apk`，数据保留（需使用相同 release 签名）。
- 首次安装：允许安装未知来源应用后安装。
- 系统要求：Android 10（API 29）及以上。
- 版本检查入口：「我的 → 关于 → 检查更新」；仓库为 `salt-fishes/Ech0-Mobile`。
