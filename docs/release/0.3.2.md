# Ech0 Mobile v0.3.2

## 概览

这次更新把友链从「只看一页、只能跳浏览器」变成完整聚合：上滑加载更多，远端说说可直接在应用内查看详情。同时新增可缩放剪裁的自定义图片背景，重做内置背景，并让「我的」同步服务器头像和用户名。0.3.1 的发布刷新、评论修复、编辑说说等改动也包含在此版本中。

## 亮点

- 友链聚合每页 20 条，上滑自动加载更多，显示「到底了 · 共 N 条」。
- 远端说说支持应用内详情：完整 Markdown、图片、标签、评论，并可跳转浏览器。
- 新增自定义图片背景：从相册选图，双指缩放、拖动剪裁，按屏幕比例保存；支持更换、重新剪裁、删除。
- 重做四套内置背景渐变，浅色 / 深色分别优化，更接近系统壁纸的冷暖层次。
- 服务端资料同步：「我的」显示服务器头像与用户名；退出登录移到账号卡右上角。
- 包含编辑说说、图片全屏查看、发布后自动刷新、评论邮箱修复等 0.3.1 改动。

## 改进

- 发布 / 编辑 / 删除说说后时间线立即刷新，不再等 3 分钟缓存。
- 图片支持全屏查看，多图可左右滑动。
- 评论新增邮箱字段并持久化；按服务端 `min_submit_ms` 等待，避免蜜罐校验失败。
- 编辑器新增上传画质（标准 / 高清 / 原图）、已有话题直接选择、位置「使用当前位置」。
- 补记弹窗明确说明「修改这条说说的发布时间」。
- 友链卡片展示完整正文，不再只显示截断预览。

## 修复

- 评论发不出去：Ech0 要求昵称和邮箱同时存在，之前缺少邮箱导致 400。
- 友链只取每个实例第一页，向下滑动没有更多内容。
- 友链远端说说只能跳浏览器，无法在应用内查看详情。
- 发布 / 编辑后列表不自动更新。
- 图片无法点击查看。
- 深色模式下「薄雾」与「暮色」背景几乎一样。

## 升级方式

- 已安装旧版本：直接覆盖安装 `ech0-mobile-0.3.2.apk`，数据保留（需使用相同 release 签名）。
- 首次安装：允许安装未知来源应用后安装。
- 系统要求：Android 10（API 29）及以上。
