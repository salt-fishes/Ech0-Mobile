# Ech0 Mobile v0.7.1

## 概览

v0.7.1 是 0.7.0 的修复版，主要解决桌面快捷方式「写一条」提示“未安装该应用”和分享链接可能缺少 `https://` 双斜线的问题。建议所有 0.7.0 用户升级；本版不包含新的界面或动效改动。

## 亮点

- 修复桌面快捷方式「写一条」无法打开的问题。
- 修复时间线分享与详情复制链接可能输出 `https:host/...` 的问题。
- 实例地址在保存和加载时统一规范化，兼容历史地址数据。

## 改进

- 实例地址统一使用规范化结果：修复 `https:/host`、`https:host` 等历史写法，去掉末尾斜杠后再用于请求和分享。
- 设置页、首启连接页和分享文案使用同一份地址，减少不同入口显示不一致。
- 0.7.0 的主题、布局和功能保持不变。

## 修复

- 桌面快捷方式「写一条」提示“未安装该应用”：快捷方式的 `targetPackage` 写死为 `top.saltfish.ech0`，与实际 `applicationId` `com.saltfish.echo` 不一致。
- 分享链接缺少 `https://` 双斜线：时间线分享和详情“复制链接”都直接拼接实例地址，历史地址异常时会输出 `https:host/...`。
- 如果覆盖安装后桌面仍保留旧快捷方式，删除旧快捷方式后重新长按应用图标 →「写一条」即可。

## 升级方式

- 已安装 0.7.0：直接覆盖安装 `ech0-mobile-0.7.1.apk`，数据保留（需使用相同 release 签名）。
- 首次安装：允许安装未知来源应用后安装。
- 系统要求：Android 10（API 29）及以上。
