# Ech0 Mobile v0.7.4

## 概览

v0.7.4 收口 0.7.x 的顶栏与媒体体验：所有页面统一为悬浮胶囊顶栏，友链能区分「没配置」和「实例暂时不可达」，图片查看器改为应用内覆盖层并接入共享元素，翻页和返回都能落回原图。建议所有 0.7.x 用户升级。

## 亮点

- 详情、设置、关于、草稿、队列、Zen、登录、内置浏览器等覆盖页统一为首页同款「左侧标题胶囊 + 右侧操作胶囊」，去掉整宽底色和分隔线。
- 图片查看器不再弹出独立窗口：缩略图放大进入全屏，左右翻页共享当前图，返回回到原缩略图。
- 图片查看器右上角提供关闭 / 保存 / 分享浮动工具栏；编辑器工具切换改为水平浮动工具栏。
- 发布按钮改为分裂按钮：直接发表，或从右侧菜单选择定时发布、公开/私密、存草稿并关闭。
- 友链会读取服务器原始 Connect 配置，把这次没有返回的实例单独列出，并支持重新检测。
- 评论排序恢复为单个图标切换，点一下在「最早 / 最新」之间切换。

## 改进

- 顶栏：首页、发现、友链、我的保留悬浮胶囊；覆盖页去掉整宽底色后统一为双胶囊结构。
- 图片布局：瀑布流完整展示 9 张图片，不再丢弃第 9 张。
- 图片查看器：支持缩放、拖动、双击放大、左右翻页和长按保存/分享；低流量和 reduceMotion 自动退化为淡入。
- 发布菜单：定时、私密、草稿入口收进发布按钮右侧，减少编辑器顶部占用。
- 友链：服务端只返回可达实例时，页面会保留上次记录并标注「未返回」，不会误显示成「还没有添加友链」。

## 修复

- 修复瀑布流布局在 9 图时第 9 张图片被裁掉的问题。
- 修复新版 Ech0 的 Connect 信息包含本站时，友链列表重复出现本站的问题。

## 升级方式

- 已安装 0.7.x：直接覆盖安装 `ech0-mobile-0.7.4.apk`，数据保留（需使用相同 release 签名）。
- 首次安装：允许安装未知来源应用后安装。
- 系统要求：Android 10（API 29）及以上。
