# Ech0 Mobile v0.5.2

> 状态：已构建，等待发布。

## 概览

v0.5.2 主要修复刷新重复和详情加载体验：时间线与友链去重、刷新和分页不再并发；本站详情和友链详情都加入本地缓存，重新进入或断网时先显示上次内容。同时放大友链头像、下调首页字号，并扩大底部渐隐范围。

## 亮点

- **详情页缓存**：本站详情和友链详情打开过一次后，会先显示缓存的正文、图片和评论，再后台刷新；断网也能查看。
- **刷新去重**：刷新与加载更多串行执行，列表按 ID 去重，解决相同内容出现两次的问题。
- **友链头像调整**：头像增大到 40dp，站点名 / 日期两行与头像上下对齐。
- **首页字号统一**：时间线正文改为与友链一致的 14sp / 21sp 行高，浏览密度更接近。
- **底部渐变加强**：渐隐范围扩大到 160dp，白色底更靠下，列表与 dock 的过渡更自然。

## 改进

- 友链聚合同时按说说 ID 去重，避免同一实例别名或多来源造成重复。
- 详情缓存会在评论加载、刷新和发表评论后更新。
- 详情页网络失败时保留缓存内容，不再清空成错误页。
- 底部内容留白同步增大，最后一条内容不会被 dock 遮挡。

## 修复

- 刷新后同一内容出现两次。
- 友链头像偏小、右侧两行与头像不对齐。
- 详情页没有缓存，重新进入或断网时需要等待网络。
- 首页正文字号比友链大。
- 底部渐变范围偏小、白色区域过高。

## 升级方式

- 已安装旧版本：直接覆盖安装 `ech0-mobile-0.5.2.apk`，数据保留（需使用相同 release 签名）。
- 首次安装：允许安装未知来源应用后安装。
- 系统要求：Android 10（API 29）及以上。
