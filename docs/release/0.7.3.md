# Ech0 Mobile v0.7.3

## 概览

v0.7.3 是 0.7.x 的收口版本：统一覆盖页顶栏与主页面视觉，友链卡片补齐点赞/评论/分享，友链详情与首页详情对齐；同时修复共享元素转场圆角和栏位遮挡问题，并补齐评论身份、图片查看器翻页、ButtonGroup、M3E Slider、刷新加载态与启动/登录构图。建议所有 0.7.x 用户升级。

## 亮点

- 桌面快捷方式「写一条」冷/热启动直接进入编辑器；未配置或未登录时进入对应引导。
- 时间线、友链、发现、我的以及详情/设置/关于/草稿/队列/Zen 等覆盖页使用统一的实底顶栏与标题胶囊。
- 友链聚合卡片支持点赞、评论、分享；远端点赞走实例公开 like 接口，并记住已赞状态。
- 友链详情与首页详情统一：同款卡片、点赞、复制链接、评论排序、加载与空态。
- 图片查看器支持左右滑动切换，同时保留双指缩放、拖动、双击放大和长按保存/分享。
- 评论输入区统一 18dp 圆角与间距；填写身份后发送时询问「保存并发送 / 仅本次发送」。

## 改进

- 我的页去掉与 Hero Header 重复的账号卡，把「账号与实例」并入菜单。
- 共享元素 overlay 按卡片/图片圆角裁剪，并按「顶栏下沿 ~ dock 上沿」做视口裁剪，避免图片变直角和返回时先浮到栏位上层再闪回。
- 设置、详情、草稿、队列等页面的选择组迁移到完整 M3 `ButtonGroup`；选项较多时回退为可换行 chip，避免窄屏挤压。
- 设置字号、背景暗化、图片质量、编辑器画质和图片编辑器笔刷改用新版 `SliderState` / expressive track。
- 刷新按钮刷新中显示 M3E `LoadingIndicator`，不再使用手写旋转动画。
- 启动页加入品牌图标缩放/淡入节奏；登录页加入品牌 Hero 与卡片式表单；连接引导统一圆角与品牌图标容器。
- 顶部紧凑栏、dock 与帖子卡片保持同一内容宽度；卡片评论/分享只留图标。

## 修复

- 修复共享元素转场中封面图短暂变直角的问题。
- 修复从详情返回时，帖子被顶栏或 dock 遮挡会先浮到栏位上面再闪回的问题。
- 修复评论身份输入后字段消失、无法确认是否保存为默认身份的问题。
- 修复友链远端卡片无法点赞，以及远端已赞状态在返回列表后丢失的问题。

## 升级方式

- 已安装 0.7.x：直接覆盖安装 `ech0-mobile-0.7.3.apk`，数据保留（需使用相同 release 签名）。
- 首次安装：允许安装未知来源应用后安装。
- 系统要求：Android 10（API 29）及以上。
