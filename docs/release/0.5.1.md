# Ech0 Mobile v0.5.1

> 状态：已构建，等待发布。

## 概览

v0.5.1 集中打磨编辑器和评论体验：卡片支持粘贴链接直接识别，工具栏加入独立的位置和话题入口；评论改为整体容器和扁平回复列表，点评论即可回复。同时新增首页 / 友链按月侧栏、详情返回保留滚动位置、草稿编辑修复和全局背景模糊。

## 亮点

- **按月侧栏**：首页和友链新增日历按钮，右侧按年份 / 月份展示时间线，点月份快速跳转；月份尚未加载时会自动向后加载。
- **评论新交互**：去掉每条评论的「回复」按钮，点评论自动弹出输入法；点其他位置取消，已输入文字时保留回复对象，并显示「回复 xxx」提示。
- **评论新视觉**：整个评论区共用一个底色容器，一级评论与二级回复改为扁平列表，回复缩进并使用更小头像。
- **卡片粘贴识别**：卡片弹窗顶部可直接粘贴链接，自动识别 GitHub / B 站 / YouTube / 音乐 / X / 地图 / 网站并填好字段。
- **编辑器工具调整**：「位置」独立为工具栏按钮，放在「补记」后面；「话题」恢复为底部小按钮。
- **背景模糊**：设置里可开启自定义背景模糊，所有页面统一生效。

## 改进

- 友链卡片的日期时间移到头像旁、名称下方。
- 从详情页返回时间线 / 友链时恢复离开前的滚动位置。
- 草稿箱点「编辑」可以直接打开编辑器并恢复草稿内容。
- 位置卡片弹窗的保存 / 取消按钮移出滚动区域，始终可见。

## 修复

- 草稿箱「编辑」点击后没有反应。
- 卡片弹窗不能直接粘贴链接、必须先手动选择类型。
- 评论回复按钮冗余、回复状态不清晰。
- 从详情返回后列表回到顶部。
- 二级评论每条单独卡片、层级不明显。

## 升级方式

- 已安装旧版本：直接覆盖安装 `ech0-mobile-0.5.1.apk`，数据保留（需使用相同 release 签名）。
- 首次安装：允许安装未知来源应用后安装。
- 系统要求：Android 10（API 29）及以上。
