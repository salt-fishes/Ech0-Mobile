# Ech0 Mobile v0.7.5

## 概览

v0.7.5 收口 0.7.x 的图片查看器、设置选择器和音乐体验。图片查看器改为长按操作并保留共享元素转场，设置选择器统一 M3E `ButtonGroup`，音乐卡补上可拖动进度条、远程实例 Meting 配置和网易云短链解析。建议所有 0.7.x 用户升级。

## 亮点

- 图片查看器右上角操作改为长按显示，2.6 秒后自动隐藏，单击图片也会收起。
- 打开查看器时先用列表缩略图占位放大，背景单独压暗，原图在转场结束后淡入；退出缩回原缩略图并保持滚动位置。
- 设置页、图床上传和扩展卡类型的选择器统一为 M3E `ButtonGroup`，超过 4 项按 3 列换行。
- 音乐卡进度条支持拖动定位，拖动时跟手、松手后 seek，暂停状态也能定位。
- 友链里的远程音乐帖改用来源实例的 `meting_api`，并支持网易云 `163cn.tv` 分享短链。

## 改进

- 图片布局：「无」布局不再显示图片；瀑布流从 2 张图起生效；轮播改为单图分页并带页码点；发布页重新提供布局入口和缩略预览。
- 图片布局说明：设置里的默认布局只影响新发布的说说，已有说说沿用发布时的布局。
- 音乐请求继续与网页端对齐：浏览器 UA、`Origin` / `Referer` / `Accept-Language`、IPv4 优先、25 秒超时。
- 音频先由 OkHttp 下载到缓存再交给 `MediaPlayer`，保留代理、302 和 IPv6 处理；代理下国内 CDN 不通时自动直连重试。
- 来源实例没有配置 Meting 时回退到可用公共实例，不再直接返回空结果。

## 修复

- 修复友链远程音乐帖使用当前实例空 `meting_api` 导致「音乐信息加载失败」的问题。
- 支持网易云 `163cn.tv` 短链：先跟随 302 到 `y.music.163.com` 再解析歌曲 ID。
- 无法识别的音乐链接改为「无法识别这个音乐链接，点按打开」，不再误报加载失败。
- 修复图片查看器打开时的黑色闪烁、返回跳回顶部和操作按钮常驻遮挡。
- 修复瀑布流「无」布局仍显示图片、轮播不分页和发布页缺少布局入口的问题。
- 修复友链图片点击被整张卡片抢走、GitHub / B 站 / X 元数据超时闪退的问题。

## 升级方式

- 已安装 0.7.x：直接覆盖安装 `ech0-mobile-0.7.5.apk`，数据保留（需使用相同 release 签名）。
- 首次安装：允许安装未知来源应用后安装。
- 系统要求：Android 10（API 29）及以上。
