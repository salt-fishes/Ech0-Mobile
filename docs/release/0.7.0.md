# Ech0 Mobile v0.7.0

## 概览

v0.7.0 以 Material 3 Expressive 2.0 为主题：统一圆角层级、强调字体、弹簧动效和设置二级页顶栏，并在编辑器、详情、月份面板和悬浮 dock 上补齐 M3E 表达。图片链路也完成了一轮升级，支持画质 / 格式档位、预览内编辑、网格管理、发布进度和失败回退。此版本还新增可选的图床上传：图片可先传到 Superbed / EasyImage / 兰空 Lsky / S.E.E / SM.MS 或自定义图床，再把外链登记到实例，实例本地不保存原图。

## 亮点

- **M3E 2.0 视觉与动效**：统一 20 / 28 / 32dp 圆角层级、emphasized 字体、Connected Button Group、减少动效和 shared-axis 设置转场。
- **图片链路升级**：画质压缩（30%）/ 原图 / 自定义，WebP / JPG / PNG / 原格式；只在点「发表」时压缩并上传。
- **图片查看与编辑**：首页图片可直接全屏查看；预览内支持裁剪、缩放、旋转、画笔和马赛克；网格长按管理、拖动排序。
- **发布进度**：顶部 `LinearWavyProgressIndicator` 展示图片上传与发布进度，失败时恢复编辑器并保留错误。
- **图床上传（可选）**：Superbed / EasyImage / 兰空 Lsky / S.E.E / SM.MS / 自定义；Token 用 Android Keystore 加密；图片先传图床，再通过 `/api/files/external` 登记外链，实例本地不保存原图。
- **无障碍与细节**：200% 字号下 dock 隐藏文字标签；减少动效统一；标签、空态、评论排序与列表返回位置一并收尾。

## 改进

- 设置分类卡、分组卡、详情评论卡、Hub 友链卡统一为 20dp；账号卡 32dp；时间线 `EchoCard` 从 28dp 调整为 20dp。
- 设置分类标题、分组标题、Section 标题改用 emphasized 样式；发现 SectionCard 标题与随机卡同步调整。
- 编辑器展开、拖拽 settle、内容尺寸动画改用 `MotionScheme`；详情点赞使用 `fastSpatialSpec()`。
- 图片格式支持 WebP / JPG / PNG / 原格式；画质收敛为压缩（30%）/ 原图 / 自定义三档，自定义可拖动压缩比例。
- 图片在编辑器内只保留本地文件；点「发表」后才批量压缩并上传，保存草稿不会触发上传；编辑结果先写入 `cache/edited_images`。
- 发布上传不再让透明编辑器拦截触摸；上传重试时单张进度不会回退到 0。
- **图床上传**：设置 → 高级与关于新增图床配置，支持预设和高级参数；切换预设会清空旧 Token 并关闭开关；提供「测试图床」「清除 Token」「恢复默认」。
- **图床兼容**：Superbed 使用表单 `token`（不再发送 `X-API-Key` 头）；EasyImage 支持无 Token 上传；S.E.E 与 SM.MS 拆成独立预设，SM.MS 认证头不带 `Bearer` 前缀。
- **图床注意**：登记外链需要管理员账号；删除说说只解除实例登记，不会删除图床原图；Token 只保存在本机。
- 减少动效下刷新按钮停止旋转；200% 字号下悬浮 dock 隐藏文字标签，保留图标与 contentDescription。

## 修复

- 行距设置不作用于 emphasized 字体。
- 设置页 13 处 `SegmentedButton` 与 M3E 规范不一致。
- 卡片圆角 16/28dp 混用，缺少统一层级。
- 点赞、编辑器、发现随机卡等自定义弹簧绕过 `MotionScheme`。
- 可点击标签与只读标签视觉不一致。
- 编辑图片完成后，网格缩略图仍显示旧图，需重新点开才刷新。
- 上传重试时单张进度从 0 重新开始，导致总进度条回退。
- 发布上传时透明编辑器仍拦截触摸，导致上传中无法操作其他页面。
- 特殊编码图片压缩失败或服务端不兼容 WebP 时直接失败；现在回退原图 / JPEG 并显示具体错误。
- 原图 / 原格式上传时，`file://` PNG 可能被按默认 JPEG 命名，导致扩展名与实际内容不一致；现在按文件头识别 PNG / JPEG / WebP / GIF / AVIF。
- 图床登记失败不再整张重传：编辑器只重试登记，发布队列用 `bed:` 标记复用已上传的外链。

## 升级方式

- 已安装旧版本：覆盖安装 `ech0-mobile-0.7.0.apk`，数据保留（需使用相同 release 签名）。
- 首次安装：允许安装未知来源应用后安装。
- 系统要求：Android 10（API 29）及以上。
