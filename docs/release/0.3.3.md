# Ech0 Mobile v0.3.3

## 概览

这是一个修复版本，解决部分从旧版本升级的用户「检查更新」一直显示已是最新 0.3.0 的问题。原因是早期版本把旧仓库 `saltfish/ech0-mobile` 写进了本地设置，而这个仓库已经不存在。0.3.3 起固定检查 `salt-fishes/Ech0-Mobile`，并自动迁移旧值。

## 亮点

- 检查更新不再读取历史仓库配置，固定使用当前仓库。
- 启动静默检查和关于页手动检查都走同一逻辑。
- 旧版本写入的错误仓库值会自动迁移，无需手动清数据。

## 改进

- `UpdateChecker` 统一使用 `DefaultGitHubRepo`。
- `Ech0Store` 读取仓库配置时自动把 `saltfish/ech0-mobile` 纠正为 `salt-fishes/Ech0-Mobile`。
- 本版本同时包含 0.3.2 的友链分页、应用内详情、自定义背景、服务端资料同步等功能。

## 修复

- 旧版本 DataStore 保存 `saltfish/ech0-mobile` 导致 GitHub API 404，检查更新误判为「已是最新」。
- 手动检查和启动静默检查的仓库来源不一致问题。

## 升级方式

- 已经能正常检查更新的用户：直接覆盖安装 `ech0-mobile-0.3.3.apk`，数据保留。
- 仍停留在 0.3.0、且检查更新显示「已是最新 0.3.0」的用户：需要手动安装一次 0.3.3；安装后后续检查更新即可正常工作。
- 首次安装：允许安装未知来源应用后安装。
- 系统要求：Android 10（API 29）及以上。

## 校验

```text
SHA-256: 070fdf579293bb3306b8893047ca176778df808f73785c8cf1e40ae682faf718
```

下载 `ech0-mobile-0.3.3.apk` 后核对同目录的 `.sha256` 文件；不一致请勿安装。
