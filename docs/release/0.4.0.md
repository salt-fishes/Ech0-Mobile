# Ech0 Mobile v0.4.0

## 概览

这次更新集中处理浏览、图片、卡片、定位和评论体验：新增低流量模式；图片查看支持缩放与长按保存 / 分享；扩展卡片可以从链接自动识别；补记改用日期和时间选择器；友链详情补上图片、头像、评论和卡片；同时修复了定位在只给大致位置时失败的问题。

## 亮点

- **低流量模式**：设置 → 流量里开启后，不再请求头像、图片和扩展卡封面，只保留文字。原来的「图片 / 上传前压缩」设置项已移除，画质仍在编辑器底部切换。
- **图片查看手势**：双指缩放、拖动、双击放大；长按图片可保存到系统相册或分享给其他应用。
- **自动识别扩展卡片**：正文里的 GitHub 仓库、B 站 / YouTube 视频、网易云 / QQ 音乐、X 推文、网站和位置链接会自动显示为卡片。
- **补记选择器**：补记改为日期选择器 + 时间选择器，不再手输 `YYYY-MM-DD`。
- **评论默认身份**：设置里可保存昵称、邮箱、网站；评论时自动带入，也可以关闭默认身份，改为每次手填。
- **友链详情完整化**：远端说说可以直接发评论，图片、服务端头像和扩展卡片都能正常显示。

## 改进

- **友链来源**：自己的帖子显示服务端头像和站点名，不再显示成默认的 Ech0。
- **近 30 天热力图**：没有发布的日期也保留隐约格子，30 天范围始终完整可见。
- **静默刷新**：后台刷新不显示进度和错误，只在发现新内容时提示「有 N 条新内容」；手动刷新和启动后第一次刷新仍正常显示进度。
- **定位**：同时请求精确 / 大致位置权限；只授予大致位置时改用网络定位；GPS 不可用时回退 last-known，并增加超时提示。
- **友链请求隔离**：访问其他实例时不再携带本站登录 Token。

## 修复

- 定位报「无法获取」：Android 12+ 只给大致位置时仍尝试 GPS provider，导致权限异常或一直拿不到坐标。
- 友链详情不显示图片：远端图片使用了本站 base URL 拼接。
- 友链详情不能评论：补充远端评论表单、验证码和提交接口。
- 友链详情头像 / 卡片缺失：读取远端 `/api/connect` 并使用扩展卡片渲染。
- 「自己的友链来源是 Echo」：服务端 Connect 信息仍是安装默认值；已同步站点名称、地址和头像，并在 App 侧增加兜底。

## 升级方式

- 已安装旧版本：直接覆盖安装 `ech0-mobile-0.4.0.apk`，数据保留（需使用相同 release 签名）。
- 首次安装：允许安装未知来源应用后安装。
- 系统要求：Android 10（API 29）及以上。
