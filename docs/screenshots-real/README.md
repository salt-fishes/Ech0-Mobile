## 真机发现并修复

1. **站点 logo 加载失败导致顶栏空白**：真机线上 logo URL 失败时，`AsyncImage` 没有 fallback；已改为“树标垫底 + 站点 logo 覆盖”，失败时仍显示品牌树标。
2. **协程离开组合被当成刷新错误**：真机出现过 `刷新失败：The coroutine scope left the composition`；已在时间线/发现/友链/详情/发布器/登录设置统一忽略取消类异常，不再把协程取消展示为用户错误。
3. **361dp 窄屏**：设置页 4 个背景预览自动换成 2 行；我的/时间线/底栏无溢出。
