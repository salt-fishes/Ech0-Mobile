## 0.3.0 已验证

- 启动静默内容刷新：冷启动后时间线自动更新，Tab 切换仍走 3 分钟 TTL
- 启动动效每个进程只播一次；真机与模拟器均正常
- 色盘：拖动选色页面不滚动，主题色、按钮、背景预览实时跟随
- 点赞：列表 / 详情共用计数；详情头部与操作行一致；不可取消时提示统一
- 关于页检查更新：启动静默检查 + 手动检查，404 / 已是最新均不报错
- 覆盖页上的 Snackbar 可见；冷启动不再误弹连接引导
- 构建：`gradlew :app:assembleRelease` 通过；Release APK 签名与 0.2.0 一致
