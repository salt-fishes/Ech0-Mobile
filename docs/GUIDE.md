# Ech0 Mobile 操作指南

适用于 **Ech0 Mobile 0.5.3**（Android 10 / API 29 及以上）。截图来自本地 mock 实例，实际界面以你的站点为准。

> 快速开始：安装 APK → 填实例地址 → 登录 → 在时间线或底部「+」发布。

---

## 1. 安装

1. 打开 [Releases](https://github.com/salt-fishes/Ech0-Mobile/releases) 下载最新 `ech0-mobile-X.Y.Z.apk`。
2. 手机提示「未知来源应用」时，允许当前文件管理器 / 浏览器安装。
3. 覆盖安装旧版本会保留数据，但必须使用同一张 release 签名；签名不一致时只能卸载重装（会清空本地草稿、队列和登录状态）。

## 2. 首次连接实例

首次启动会进入连接页：

1. 填完整实例地址，例如 `https://echo.example.com`（带 `https://`，不要带 `/api`）。
2. 点「连接」；成功后进入时间线。
3. 想稍后再填，可以点「先逛逛」，之后在「我的 → 设置 → 实例地址」补上。

如果连接失败：

- 先用手机浏览器打开 `https://你的实例/api/hello`，确认能返回 JSON。
- 检查地址是否写成了 `http://`、是否多了结尾 `/`。
- Cloudflare / 反向代理开启人机验证时，App 的接口请求可能被拦截。

## 3. 登录

### 3.1 用户名密码（推荐日常使用）

1. 底部「我的」→「登录 Ech0」。
2. 填实例地址、用户名、密码。
3. 登录成功后，「我的」会显示用户名和管理员标识。

> 用户名是 Ech0 的账号名，不是邮箱；连续失败时先到 Web 端确认账号是否可登录。

### 3.2 Access Token（适合脚本 / 不想存密码）

1. 用管理员账号登录 Ech0 Web 端。
2. 进入 **系统设置 → 访问令牌 → 新建**。
3. 建议配置：
   - **Audience**：`公开客户端`（`public-client`）或 `命令行`（`cli`）
   - **Scopes**：`profile:read`、`echo:read`、`echo:write`、`comment:read`、`comment:write`、`file:read`、`file:write`、`connect:read`
   - **有效期**：按需要选择；长期令牌请只放在可信设备
4. 创建后立即复制（完整 token 只显示一次）。
5. App：「我的 → 设置 → 高级 · Access Token 登录」→ 粘贴 →「验证并保存」。

注意事项：

- **不要**选 `系统集成 / integration` 或 `MCP / mcp-remote` 来登录 App。前者只用于集成评论，后者只用于 `/mcp`。
- 缺少 `profile:read` 时，App 验证会报「令牌权限范围不足 / SCOPE_FORBIDDEN」。
- Token 在 App 内用 Android Keystore 加密保存，release 包无法读出明文；忘记后只能在 Web 端删除重建。

## 4. 时间线

| 操作 | 方式 |
|---|---|
| 刷新 | 下拉列表，或点右上角刷新按钮；启动时会先显示缓存再静默同步 |
| 搜索 | 点右上角放大镜，输入关键词 |
| 标签筛选 | 点帖子里的标签 chip，再点一次顶部标签可取消 |
| 点赞 | 点心形；Ech0 服务端没有 unlike 接口，已赞后不可取消，再点会提示 |
| 评论 | 点「评论」进入详情；支持回复和游客评论 |
| 分享 | 点「分享」调用系统分享面板 |
| 删帖 | 管理员长按帖子卡片，确认后删除 |

> 缓存策略：先显示上次内容，再在后台刷新；同一进程内切换 Tab 有 3 分钟 TTL，下拉刷新始终生效。

## 5. 发现

- **今日 / 热门 / 那年今日**：三个分区，热门按点赞和评论加权。
- **30 天热力图**：看最近发布节奏。
- **标签云**：点标签跳到对应筛选。
- **随机一条**：从历史内容里随机抽一条。
- **Zen 瀑布流**：沉浸式浏览，适合看图片。

## 6. 友链

- 「友链」页会读取本站和互联实例，按时间归并聚合。
- 每张卡片带来源 chip，点来源可跳到对应实例。
- 支持 Markdown、媒体缩略图和「N 图」标记。

## 7. 发布说说

1. 点底部中央「+」，打开写说说抽屉；可上拖全屏。
2. 输入正文，支持 Markdown。
3. 点「图片」选择照片（最多 9 张），上传前会压缩为 WebP（画质可在编辑器底部切换）。
4. 可选：
   - 「话题」添加标签
   - 「公开」切换公开 / 私密
   - 「卡片」添加网站 / 视频 / 音乐 / GitHub / 位置 / 推文扩展
   - 「补记」修改发布时间
5. 点「发表」。

发布失败或断网时会进入发布队列，按网络约束和指数退避自动重试；可在「我的 → 发布队列」查看、重试或删除。编辑中的内容会自动存草稿，在「我的 → 草稿箱」恢复。

## 8. 我的

- **草稿箱**：本地自动保存的未发布内容。
- **发布队列**：待发 / 失败任务。
- **设置**：实例地址、外观、低流量模式、评论默认身份、Access Token。
- **关于**：版本、实例信息、检查更新、更新记录、技术栈。

## 9. 外观

设置页「外观」支持：

- **跟随系统 / 浅色 / 深色**
- **动态取色**：Android 12+ 从壁纸取色；关闭后显示主题色盘
- **主题色盘**：拖动色相 / 饱和度选色，实时预览；停止拖动约 180ms 后保存
- **背景**：默认 / 纸张 / 薄雾 / 暮色

色盘为 160dp，拖动时不会带着设置页上下滚动。

## 10. 检查更新

- App 启动后会静默检查 GitHub Release，失败不打扰。
- 手动检查：「我的 → 关于 → 检查更新」。
- 发现新版本会显示更新记录，可打开 APK 下载页或 Release 页。
- **只做检查与下载引导，不会自动安装 APK**；安装仍需系统确认。
- 如果一直显示「已是最新版本」，说明当前版本不低于 `releases/latest`，或网络无法访问 GitHub。

## 11. 常见问题

### 登录报「令牌权限范围不足」

Token 缺少 `profile:read`，或 Audience 选成了 `integration` / `mcp-remote`。到 Web 端新建 `public-client` token，按第 3.2 节勾选 scopes。

### 登录报「用户不存在」

用户名写错（注意大小写），或填成了邮箱。用 Web 端能登录的账号名再试。

### 一直提示「刷新失败」

- 0.3.0 已修复协程取消被误报为刷新失败的问题，先确认版本。
- 检查实例是否可访问、是否被 Cloudflare 拦截、登录是否过期。
- 下拉刷新或到设置页点「测试连接」。

### 点赞后无法取消

Ech0 服务端只有 `PUT /api/echo/like/{id}`，没有 unlike 接口。App 的点赞是单向的，已赞后再次点击只会提示，不会改服务端计数。

### 内容不是最新

启动时会静默同步一次；之后切换 Tab 有 3 分钟缓存。下拉刷新可强制拉取。离线时继续显示磁盘缓存。

### 覆盖安装提示签名不一致

新旧 APK 不是同一张证书。只能卸载旧版再装（会清空本地数据），或换回原签名包。

### 想撤销/更换 Token

到 Ech0 Web 端「系统设置 → 访问令牌」删除旧令牌，新建一枚；在 App 设置页重新粘贴验证。删除后旧 token 立即失效。

## 12. 数据与隐私

- Access Token 使用 Android Keystore 加密后写入 DataStore，release 包不可调试读取。
- 点赞记录、草稿、发布队列保存在本机；卸载会清空。
- 时间线 / 发现 / 友链有磁盘缓存，用于离线展示。
- 退出登录不会删除草稿和缓存；需要彻底清理时在系统设置里清除应用数据。
